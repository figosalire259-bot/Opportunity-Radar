## 机会评估标准
每个机会按以下维度打分（1-5分）：
- 市场规模：用户有多少
- 痛点强度：用户有多痛
- 竞争程度：竞品有多强（反向，竞品越弱分越高）
- 实现难度：技术难不难（反向，越简单分越高）
- 变现能力：能不能赚钱

总分>15分：值得做
总分10-15分：继续观察
总分<10分：放弃
